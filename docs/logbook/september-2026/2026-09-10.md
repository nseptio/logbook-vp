## Hal yang Dipelajari

### Alur Integrasi TR 500000 pada Aplikasi Flutter

Untuk menampilkan grafik Trade Flow selama satu hari perdagangan penuh, aplikasi Flutter hanya memerlukan **1 kali request socket TCP**. 

Alur pemrosesan data berjalan dalam tahapan berikut:

#### 1. Pengiriman Request oleh Klien
Aplikasi mengirimkan satu paket teks berformat *pipe-delimited* melalui koneksi socket TCP:

```text
00001|TLKM|RG|20260826|20260826|vol|
```
- `00001`: Nomor urut sekuens transaksi.
- `TLKM`: Kode saham.
- `RG`: Papan perdagangan (Pasar Reguler).
- `20260826`: Tanggal perdagangan yang diminta.
- `vol`: Satuan perhitungan data (`vol` untuk Lot atau `val` untuk Rupiah).

#### 2. Pengolahan Data di Server
- Server memproses data rekaman transaksi intraday bursa dari file binary `.tf` (*trade flow*) menggunakan modul pembaca internal.
- Data dikelompokkan ke dalam **320 titik data menit**, sesuai total menit aktif perdagangan Bursa Efek Indonesia (IDX) dalam sehari:
  - **Sesi 1 (09:00 – 12:00 WIB):** 180 menit.
  - **Sesi 2 (13:30 – 15:50 WIB):** 140 menit.
  - Total: 320 menit.
- Setiap menit memuat data waktu, harga penutupan menit, volume beli agresif (HAKA), volume jual agresif (HAKI), volume bersih (*net flow*), dan rasio transaksi.

#### 3. Format Respons dari Server
Server mengembalikan seluruh 320 data menit tersebut dalam satu string tunggal yang dipisahkan karakter pipa (`|`):

```text
320|09:00|2850|12000|0|...|15:50|2870|0|4500|total_haka|total_haki|...|
```

#### 4. Parsing dan State Management di Flutter
- Respons diterima melalui *stream socket* oleh `TradeFlowService`.
- Method `getTradeFlowData` memecah string tersebut berdasarkan delimiter `|` dan memetakannya ke dalam objek model Dart `TradeFlowPoint`:
  ```dart
  TradeFlowPoint(
    timestamp: DateTime(2026, 8, 26, hour, minute),
    price: parsedPrice,
    buyLot: parsedHaka,
    sellLot: parsedHaki,
  )
  ```
- Kumpulan data tersebut dimasukkan ke dalam state menggunakan `TradeFlowCubit` untuk diteruskan ke komponen UI.

#### 5. Rendering Visual pada Grafik
Widget `trade_flow_chart.dart` menggunakan library `fl_chart` untuk menampilkan dua layer data secara sinkron:
- **Bar Chart (Sumbu Y Kiri):** Menampilkan nilai `netLot` (`buyLot - sellLot`). Nilai positif ditampilkan sebagai batang hijau ke atas (dominasi beli/HAKA) dan nilai negatif sebagai batang merah ke bawah (dominasi jual/HAKI).
- **Line Chart (Sumbu Y Kanan):** Menampilkan garis pergerakan harga saham sepanjang sumbu X waktu.
