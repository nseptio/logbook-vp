## 1. Apa yang telah Dikerjakan

Hal yang dikerjakan hari ini terkait dengan **KYC - Opening Account**, tepatnya untuk fitur *"Spouse Information"* sesuai dengan tiket Jira (AKS-44).

### Mengubah URL API yang sebelumnya mengarah ke project AO menjadi SQ

```dart
// lib/pages/kyc_resubmit/kyc_preview_resubmit/spouse/spouse_resubmit.dart

// Sebelumnya (hardcode URL):
- final response = await http.get(Uri.parse("https://api-dev.example.com/KYC/province-city"));

// Sesudah (menggunakan variabel konfigurasi agar mudah diubah):
+ const apiUrl = String.fromEnvironment(
+   'BASE_API_URL',
+   defaultValue: 'https://api-sq.example.com/kyc',
+ );
+ final response = await http.get(Uri.parse("$apiUrl/province-city"));
```

Karena URL sebelumnya tersebar dalam beberapa bagian kode dan masih *hardcode*, saya membuat variabel pada file `spouse_resubmit.dart` untuk URL API agar perubahan URL berikutnya dapat dilakukan dengan lebih mudah.

Solusi ini masih dapat dikembangkan dengan menggunakan *global configuration* atau *config file* (mungkin semacam dotenv) untuk menyimpan konfigurasi seperti API URL. Dengan demikian, konfigurasi tidak perlu didefinisikan langsung di banyak file secara manual (dapat dilihat pada commit `ceb271f`).

## 2. Apa yang telah Dipelajari

Pada hari ini saya mencari tahu tool **fzf (Fuzzy Finder)**, yaitu command-line tool yang memungkinkan pengguna melakukan pencarian secara interaktif menggunakan metode *fuzzy matching*. Dengan fzf, pencarian file, command, maupun direktori pada server dapat dilakukan dengan lebih cepat tanpa harus mengetik nama atau path secara lengkap. Dapat lihat lebih lengkap pada GitHub Repository [junegunn/fzf](https://github.com/junegunn/fzf).

*fzf* dapat diinstall langsung di Windows melalui Winget, Scoop, atau package manager lainnya. *fzf* juga memiliki beberapa *shortcut* yang berguna dalam pekerjaan sehari-hari, seperti:

- **Ctrl+T** untuk mencari file secara interaktif. Saya dapat menggunakannya untuk mengecek apakah file *TR dengan nomor tertentu* sudah tersedia pada server SQ lebih mudah.  
  ![fzf Ctrl+T](/images/september-2026/2026-09-01/06.png)

- **Ctrl+R** untuk mencari command yang pernah dijalankan melalui *shell history*, sehingga command sebelumnya dapat ditemukan dan dijalankan kembali dengan lebih mudah.  
  ![fzf Ctrl+R](/images/september-2026/2026-09-01/07.png)

- **Alt+C** untuk mencari dan berpindah ke direktori secara interaktif, sehingga navigasi pada server menjadi lebih cepat tanpa harus mengetik path direktori secara lengkap.  
  ![fzf Alt+C](/images/september-2026/2026-09-01/08.png)
