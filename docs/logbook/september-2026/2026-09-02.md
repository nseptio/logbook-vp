### Build APK dari Project Flutter

Memahami proses build aplikasi Flutter dalam mode release, khususnya proses konfigurasi `signingConfigs` pada file `build.gradle`. Untuk build APK dari proyek Flutter, pastikan sudah menginstall semua dependency dengan menjalankan command `flutter pub get`. Setelah itu, jalankan `flutter build apk --release`.

Terdapat kendala karena file `key.properties` yang dibutuhkan untuk konfigurasi release signing tidak tersedia pada environment yang digunakan. Oleh karena itu saya perlu menambahkan konfigurasi fallback ke debug keystore apabila `key.properties` tidak tersedia, sehingga proses build tetap dapat dijalankan pada kondisi tersebut.

![Konfigurasi Fallback Debug Keystore](/images/september-2026/2026-09-02/01.png)

Perubahan tersebut tidak di-*commit* untuk menghindari kemungkinan gagal build di device lain.

Setelah menambah `debug.keystore`, command `flutter build apk --release` dapat berjalan tanpa kendala dan APK berhasil di-build.

![Hasil Build APK Flutter](/images/september-2026/2026-09-02/02.png)

### Konversi Private Key .ppk Menjadi OpenSSH

Untuk mengakses remote server, dibutuhkan private key untuk proses autentikasi server. Key yang diberikan berformat `.ppk` yang mana hanya bisa digunakan di aplikasi PuTTY, tidak bisa digunakan OpenSSH (*command line ssh* pada terminal). Untuk dapat menggunakan command line `ssh` pada terminal dibutuhkan format private key OpenSSH. PuTTY sudah menyediakan tool untuk konversi antar format.

Ketika menginstal PuTTY, akan tersedia juga aplikasi PuTTYgen yang mana dapat mengekspor private key format `.ppk` menjadi OpenSSH. Caranya hanya perlu `load` file `.ppk` dan eksport menjadi OpenSSH pada menu bar `Conversions`.

![PuTTYgen Load PPK](/images/september-2026/2026-09-02/03.png)

```text
Langkah Export di PuTTYgen:
1. Klik menu bar "Conversions" -> "Export OpenSSH key"
2. Simpan file private key OpenSSH ke directory ~/.ssh/ (misalnya: id_rsa)
```

Setelah memperoleh private key berformat OpenSSH, kita dapat mengakses remote server tanpa aplikasi PuTTY dengan command line `ssh` melalui terminal.

### Mengenal Tool Bernama Herdr

Memahami Herdr sebagai terminal workspace manager, yang menyediakan struktur berupa workspace, tab, dan *pane* untuk mengorganisasi beberapa terminal atau proses secara bersamaan. Dengan Herdr, kita dapat dengan mudah mengorganisir sesi terminal, salah satu contoh praktisnya adalah membuka banyak sesi SSH pada satu window. Berbeda dengan PuTTY, jika kita ingin membuka sesi baru, perlu dilakukan di window baru, jadi pengaksesan server berjalan terpecah di banyak window aplikasi PuTTY.
