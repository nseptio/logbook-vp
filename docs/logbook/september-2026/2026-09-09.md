## 2. Hal yang Dipelajari

### A. Konsep Dasar & Order Pasif
Trade Flow mencatat dan memvisualisasikan aliran selisih antara transaksi agresif secara *real-time*:
- **HAKA (Hajar Kanan):** Aktivitas membeli saham langsung pada harga penawaran (*offer*) sehingga transaksi langsung terjadi (*match*) tanpa mengantre.
- **HAKI (Hajar Kiri):** Aktivitas menjual saham langsung pada harga permintaan (*bid*) agar saham segera terjual tanpa mengantre.
- **Order Pasif:** Antrean order yang menunggu di harga Bid (ingin beli lebih murah) atau Offer (ingin jual lebih mahal). Antrean pasif ini cenderung menahan dan tidak secara langsung menggerakkan harga bursa sampai ada order agresif yang mengeksekusinya.

Untuk membaca pergerakan pasar secara komprehensif, Trade Flow disajikan dalam 3 tampilan. Masing-masing tampilan memiliki fungsi spesifik dan menjawab pertanyaan analitis yang berbeda:

#### 1. Chart View (Korelasi Waktu & Harga)

![Trade Flow Chart View](/images/september-2026/2026-09-09/01.jpg)

- **Pertanyaan yang Dijawab:**  
  > *"Bagaimana korelasi antara aliran transaksi bersih dengan pergerakan harga saham sepanjang hari?"*
- **Manfaat:**  
  Menghubungkan pergerakan garis harga saham dengan dominasi transaksi beli atau jual. Berguna untuk melihat apakah kenaikan harga memang didorong oleh banyaknya orang yang langsung membeli (batang hijau), atau harga naik tetapi sebenarnya di belakang layar lebih banyak yang menjual (batang merah).

#### 2. Price View (Distribusi Fraksi Harga)

![Trade Flow Price View](/images/september-2026/2026-09-09/02.jpg)

- **Pertanyaan yang Dijawab:**

- **Manfaat:**  
  Mengabaikan linimasa waktu dan mengelompokkan seluruh transaksi berdasarkan [[fraksi-harga|fraksi harga]]. Pengguna dapat melihat tingkat likuiditas riil di setiap level harga melalui kolom `S.Freq`, `S.Val`, dan `B.Val`.

#### 3. Time View (Log Kronologis Berkala)

![Trade Flow Time View](/images/september-2026/2026-09-09/03.jpg)

- **Pertanyaan yang Dijawab:**  
  > *"Kapan aktivitas pembelian dan penjualan paling besar terjadi sepanjang sesi bursa?"*
- **Manfaat:**  
  Mengelompokkan transaksi ke dalam interval berkala (misalnya per 10 menit) lengkap dengan perbandingan rasio `%Buy` dan `%Sell`. Membantu mengidentifikasi jam-jam krusial saat terjadi pembalikan sentimen atau lonjakan volume tiba-tiba (*momentum shift*).

### C. Support dan Resistance pada Trade Flow by Price

Tampilan *Price View* juga dapat memberikan sudut pandang tambahan ketika mengamati area support dan resistance:

- **Support:**  
  Level harga di mana penurunan harga cenderung tertahan karena banyaknya minat beli, sehingga harga berpotensi memantul naik kembali.
- **Resistance:**  
  Level harga di mana kenaikan harga cenderung tertahan karena banyaknya aksi jual, sehingga harga berpotensi berbalik turun.

#### Peran sebagai Informasi Tambahan Berbasis Volume:
Trade Flow by Price membantu kita melihat di level harga mana aktivitas transaksi besar terkonsentrasi. Pendekatan analisis berbasis volume (*volume-based analysis*) ini dapat menjadi informasi pelengkap bagi analisis teknikal:
- Alih-alih hanya mengandalkan garis puncak atau lembah harga historis, data ini menyajikan konfirmasi transaksi riil yang telah terjadi di pasar.
- Level harga yang memiliki aktivitas transaksi tinggi (akumulasi `B.Val` atau `S.Val` yang masif) memberikan gambaran objektif mengenai area harga yang sedang diperhitungkan oleh pelaku pasar, sehingga berpotensi menjadi area support atau resistance.

### D. Memahami File Permissions pada Linux

Setelah mempelajari struktur direktori sistem file kemarin, hari ini saya melanjutkan mempelajari sistem *file permissions* pada Linux berdasarkan referensi [LinuxCommand.org](https://linuxcommand.org/lc3_lts0090.php).

Pada Linux, hak akses diatur secara ketat untuk melindungi file dan proses sistem dari modifikasi tanpa izin. Saat menjalankan perintah `ls -l`, setiap file atau direktori diawali oleh 10 karakter penanda atribut:

![Struktur File Permission Linux](/images/september-2026/2026-09-09/04.png)  
*(Sumber diagram: [LinuxCommand.org - Permissions](https://linuxcommand.org/lc3_lts0090.php))*

#### 1. Karakter Pertama: Tipe File (*File Type*)
- `-` : Menunjukkan file reguler biasa (file teks, gambar, binary executable, dll.).
- `d` : Menunjukkan direktori (*directory*).
- `l` : Menunjukkan tautan simbolis (*symbolic link*).

#### 2. Tiga Kelompok Hak Akses (*Triplets*):
Sembilan karakter berikutnya dibagi menjadi 3 kelompok hak akses (`rwx`):
1. **File Owner (`u` / User):** Hak akses untuk user pemilik file.
2. **Group Owner (`g` / Group):** Hak akses untuk seluruh anggota grup pemilik file.
3. **Others (`o` / Others):** Hak akses untuk seluruh user lain di dalam sistem.

#### 3. Arti Mode Akses (`r`, `w`, `x`):
- **`r` (Read / Nilai: 4):**
  - Pada file: Izin untuk membuka dan membaca isi file.
  - Pada direktori: Izin untuk melihat daftar isi direktori (`ls`).
- **`w` (Write / Nilai: 2):**
  - Pada file: Izin untuk mengubah, menulis, atau menghapus isi file.
  - Pada direktori: Izin untuk membuat, menghapus, atau mengubah nama file di dalam direktori tersebut.
- **`x` (Execute / Nilai: 1):**
  - Pada file: Izin untuk menjalankan file sebagai program atau skrip.
  - Pada direktori: Izin untuk memasuki atau melintasi direktori (`cd`).

#### 4. Notasi Numerik (Octal):
Hak akses sering kali diatur menggunakan perintah `chmod` dengan representasi angka (penjumlahan nilai `r=4`, `w=2`, `x=1`):
- `chmod 755 file.sh` → Pemilik memiliki akses penuh (`7 = 4+2+1`), sedangkan Group dan Others hanya dapat membaca dan menjalankan (`5 = 4+1`).
- `chmod 644 file.txt` → Pemilik dapat membaca dan menulis (`6 = 4+2`), sedangkan pihak lain hanya dapat membaca (`4`).
