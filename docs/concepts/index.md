# Konsep

Bagian ini merangkum penjelasan konsep, mekanisme pasar modal, dan materi teknis yang dipelajari selama masa internship.

Setiap konsep dapat ditautkan dari catatan laporan harian menggunakan format Obsidian WikiLinks `[[nama-file|Label Tautan]]`.

---

## Pasar Modal
- [[ara-arb|Auto Rejection Atas (ARA) dan Auto Rejection Bawah (ARB)]]  
  Mekanisme pembatasan fluktuasi harga saham harian secara otomatis oleh Bursa Efek Indonesia.
- [[fraksi-harga|Fraksi Harga Saham]]  
  Aturan kenaikan dan penurunan harga penawaran saham berdasarkan rentang harga tertentu.

---

## Menulis Konsep Baru
Untuk menambahkan konsep baru, buat file `.md` di dalam folder `docs/concepts/<kategori>/<nama-file>.md`. Catatan tersebut otomatis muncul di sidebar dan dapat ditautkan dari laporan harian mana pun menggunakan format `[[nama-file]]`.
